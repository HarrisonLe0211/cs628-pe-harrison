# Input
User details such as name, contact information, education, skills, work experience, and projects. In this project, the data is retrieved through Resume.js
# Process
Rendering the Resume: The React app processes the input data (resume details) and applies the layout and styles defined in Resume.js and Resume.css to generate the webpage.
User Interactions: For now, it's limited to just a page that display information
# Output
The visual representation of the resume displayed in the web browser. This includes formatted text displaying the user’s educational background, work experience, skills, and projects in a stylized format defined in the CSS file.
